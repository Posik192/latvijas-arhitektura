
# Latvijas arhitektūra cauri laikmetiem

## 1. Projekta apraksts

Projekts ir izstrādāts praktisko mācību laikā, izmantojot HTML5, CSS3 un JavaScript.

Projekta mērķis ir izveidot interaktīvu un responsīvu virtuālo izstādi par Latvijas arhitektūru no viduslaikiem līdz mūsdienām.

- **Izstādes tēma:** Latvijas arhitektūra
- **Izstādes nosaukums:** Latvijas arhitektūra cauri laikmetiem

## 2. Projekta autors

## 3. GitHub repozitorijs

Projekta repozitorijs: https://github.com/Posik192/latvijas-arhitektura

## 4. Izmantotās tehnoloģijas

- **HTML5** – tīmekļa vietnes struktūras izveide.
- **CSS3** – dizains, Box Model, Flexbox, Grid un responsīvais izkārtojums.
- **JavaScript** – interaktīva attēlu karuseļa darbība.
- **GitHub** – projekta failu glabāšana un versiju kontrole.
- **Visual Studio Code** – koda rakstīšana un rediģēšana.

## 5. Tīmekļa vietnes funkcionalitāte

- Galvene un navigācijas izvēlne.
- Izstādes apraksts.
- Galerija ar 8 arhitektūras objektiem.
- Interaktīvs karuselis ar 8 attēliem.
- Manuāla attēlu pārslēgšana.
- Automātiska pārslēgšana ik pēc 5 sekundēm.
- Automātiskās pārslēgšanas apturēšana un atsākšana.
- Responsīvs dizains datoriem, planšetēm un telefoniem.
- Informācijas avoti un attēlu licences.
- Kājene ar autora informāciju.

## 6. Projekta palaišana

1. Lejupielādēt vai klonēt GitHub repozitoriju.
2. Atvērt projekta mapi.
3. Atvērt index.html tīmekļa pārlūkprogrammā.

## 7. Projekta izstrādes ieguldījums

Projekts tika izstrādāts individuāli.

Paveiktie darbi:

- HTML struktūras izveide.
- CSS dizaina izstrāde.
- Informācijas un attēlu atlase.
- JavaScript karuseļa programmēšana.
- Responsīvā dizaina pārbaude.
- HTML un CSS validācija.
- Projekta dokumentācijas sagatavošana.
